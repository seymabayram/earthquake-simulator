# 🌍 Earthquake Simulator

## 👩‍💻 Team: SeismicCoders

We are **SeismicCoders**, a team of three developers transforming an existing Fire Extinguisher Simulator into a realistic and interactive **Earthquake Simulation** experience.

---

## 🎯 Project Objective

The goal of this project is to redesign and repurpose an existing simulation system by replacing fire-fighting mechanics with earthquake dynamics. The simulation focuses on environmental interaction, physics-based object behavior, and user safety awareness during seismic events.

---

## ⚙️ Features

- 🌍 **Earthquake Simulation**  
  Realistic shaking effects to simulate seismic activity.

- 🪑 **Physics-Based Interactions**  
  Objects react dynamically — falling, sliding, or shifting during the earthquake.

- 🛑 **Safe Zones**  
  Designated areas (e.g., under a desk) where users must move to stay safe.

- 🎮 **Interactive Experience**  
  Users actively respond to the earthquake scenario in real time.

---

## 🧠 Technologies Used

- Unity (3D Game Engine)
- C#
- Physics Engine (Rigidbody, Collisions)
